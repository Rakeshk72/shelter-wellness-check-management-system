# Shelter Wellness Check Management System

## Capstone Project

The Shelter Wellness Check Management System is a full-stack MERN application designed to help shelter staff record, manage, and review resident wellness checks.

The application will provide a centralized system for tracking wellness check information instead of relying only on manual or paper-based records.

## Project Objective

The objective of this project is to build a full-stack web application using:

- MongoDB
- Express.js
- React
- Node.js

## Planned Features

- Add and manage residents
- Record wellness checks
- View wellness check history
- Update wellness check records
- Delete records when appropriate
- Search and filter records
- Track resident presence status
- Add staff comments
- Display wellness check information on a dashboard
- Store data in MongoDB

## Project Structure

The project is divided into two main applications:

- `backend` - Node.js, Express, MongoDB, and Mongoose
- `frontend` - React user interface

## Data Privacy

This capstone project will use fictional demonstration data only. No real shelter resident or confidential client information will be stored in the project.
